二、方案对比

方案扩缩容时 key 迁移负载均衡典型场景
取模 N几乎全部重映射均匀（节点同质时）固定分片、小规模缓存
一致性哈希约 1/n（理想）依赖虚拟节点分布式缓存、对象存储元数据
有界负载一致性哈希略高于纯 CH可限制热点节点异构、倾斜 key

三、术语表

哈希环
将哈希空间首尾相接，节点与 key 均映射到环上同一坐标系。
顺时针后继
key 归属环上顺时针方向遇到的第一个节点（含虚拟节点）。
虚拟节点（vnode）
一个物理节点在环上的多个占位，用于打散热点、改善均衡。
迁移 key
拓扑变化后，归属节点发生变化的 key；本演示用简化区间模型估算。
